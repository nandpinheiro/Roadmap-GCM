🚀 COMO COMEÇAR
═══════════════════════════════════════════════════════════════════════════

OPÇÃO 1: Usar SEM FIREBASE (Local)
─────────────────────────────────────

1. Abra index.html no navegador
2. Clique em "📚 Conteúdos"
3. Marque checkboxes
4. Preencha data e observações
5. Clique "Enviar Progresso"
6. ✓ Pronto! (Salvos no seu dispositivo)


OPÇÃO 2: Usar COM FIREBASE (Nuvem)
──────────────────────────────────────

1. Visite https://console.firebase.google.com
2. Crie um novo projeto "GCM-Roadmap"
3. Ative "Realtime Database"
4. Copie suas credenciais
5. Cole em firebase-config.js (linhas 11-18)
6. Descomente scripts do Firebase em index.html
7. Salve os arquivos
8. ✓ Pronto! (Sincronizado na nuvem)


OPÇÃO 3: Usar COM SEU PRÓPRIO SERVIDOR
────────────────────────────────────────

1. Instale Node.js: https://nodejs.org
2. Copie server-example.js para sua pasta
3. Execute: npm install express cors
4. Execute: node server-example.js
5. Modifique firebase-config.js para apontar ao seu servidor
6. ✓ Pronto! (Sincronizado no seu servidor)
