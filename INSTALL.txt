PASSO 1: Testar Localmente (5 min)
──────────────────────────────────
1. Abra index.html no navegador
2. Vá para "📚 Conteúdos"
3. Marque um checkbox
4. Veja os campos aparecerem
5. Preencha data e observação
6. Clique "Enviar Progresso"
✓ Deve aparecer "✓ Salvo localmente!"


PASSO 2: Configurar Firebase (15 min)
──────────────────────────────────────
1. Acesse https://console.firebase.google.com
2. Crie novo projeto ("GCM-Roadmap")
3. Ative Realtime Database
4. Copie credenciais
5. Cole em firebase-config.js (linhas 11-18)
6. Descomente scripts do Firebase em index.html
7. Salve e recarregue a página
✓ Agora sincroniza com a nuvem!


PASSO 3: Testar em Outro Dispositivo (5 min)
─────────────────────────────────────────────
1. Abra o link em outro navegador/tablet/celular
2. Os dados aparecem automaticamente
3. Marque mais um checkbox
4. Clique "Enviar"
✓ Sincroniza entre dispositivos!
